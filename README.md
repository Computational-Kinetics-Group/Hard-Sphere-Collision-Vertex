# Exact Collision Vertex for Stress and Heat Flux — code and data

This repository is the code/data companion to the journal submission **“Exact Collision Vertex for Stress and Heat Flux.”** It contains the exact hard-sphere Hermite coefficient generator, machine-readable coefficient tables, the retained DSMC validation scripts, and the numerical table data used for the comparisons in the Letter and Supplemental Material.

The central analytic objects are the stress and heat-flux generating vertices

\[
\mathbb S_{\alpha\beta}(z,u)=V(r^2)r_{\langle\alpha}r_{\beta\rangle},\qquad
\mathbb H_\alpha(z,u)=\tfrac12(z+u)_\beta\mathbb S_{\alpha\beta}(z,u),
\]

with \(r=z-u\). Taylor differentiation generates the universal bilinear Hermite tensors \(P\) and \(Q\). The Gaussian/Hermite representation is a computational coordinate system: after convergence, the physical Boltzmann production map is representation independent.

## 1. Exact coefficient tables

The main coefficient table can be regenerated with only the Python standard library:

```bash
python coefficients/generate_hard_sphere_PQ.py \
  --max-stress-degree 14 \
  --output hard_sphere_PQ_coefficients_through_degree15.csv
```

This produces **28,626 independent entries**, using one representative of the incoming exchange symmetry \((\nu,\lambda)\leftrightarrow(\lambda,\nu)\). Stress coefficients are generated through total degree 14; the heat-flux contraction then reaches total degree 15.

The scalar radial coefficients are generated by

```bash
python coefficients/generate_scalar_vertex_table.py \
  --max-m 6 \
  --output hard_sphere_scalar_vertex_coefficients.csv
```

using

\[
c_0=-\frac85,\qquad
c_{m+1}=-c_m\frac{2m-1}{4(m+1)(2m+7)}.
\]

The supplied `hard_sphere_PQ_coefficients_through_degree15.csv` is reproduced byte-for-byte by the supplied generator.

## 2. Wall-driven hard-sphere DSMC

The final wall-driven campaign contains four flow families and two independent replicas per family. A single run is launched as

```bash
python validation/wall_driven/scripts/dsmc_natural_campaign.py \
  --case couette --rep 1 --out campaign_couette_r1.json
```

where `--case` is one of `couette`, `fourier`, `combined`, or `strong`, and `--rep` is 1 or 2. The eight retained raw JSON outputs are included under `validation/wall_driven/data/`.

After the eight runs, the aggregate data products are regenerated by

```bash
python validation/wall_driven/scripts/aggregate_wall_campaign.py \
  --input-dir validation/wall_driven/data \
  --output-dir validation/wall_driven/data
```

This produces the aggregate JSON, the flat comparison table used for the parity plots, and the normalized-RMS summary used in the Supplemental Material.

## 3. Baseline stationary Mach-5 shock

The retained baseline shock simulation is advanced through state files. For example:

```bash
mkdir -p shock_work
python validation/shock/scripts/shock_chunk.py shock_work/shock_r1.pkl 10000
python validation/shock/scripts/shock_chunk.py shock_work/shock_r2.pkl 10000
python validation/shock/scripts/shock_postprocess.py --workdir shock_work
python validation/shock/scripts/shock_crossrep.py --workdir shock_work
python validation/shock/scripts/export_baseline_tables.py \
  --crossrep shock_work/shock_M5_crossrep.json \
  --output-dir shock_work
```

The two post-processing scripts were changed from the original working copies only to replace hard-coded `/mnt/data` paths by a portable `--workdir` option; the numerical formulas are unchanged.

The repository also contains the retained baseline aggregate/cross-replica JSON files and the publication CSVs, so reproducing plots does not require rerunning the DSMC calculation.

## 4. Derived shock tables used in the Supplement

The final publication data include:

- sampling-statistics convergence at 1x, 2x, and 4x sampling;
- disjoint-block sampling errors;
- convergence regrouped by exact total incoming Hermite degree;
- additive heat-production sectors at the shock center;
- Gaussian-reference convergence and distribution-reconstruction data.

These CSV files are the numerical table data used for the corresponding Supplemental figures and quoted comparisons. The baseline shock scripts above reproduce the original 1x campaign. The extended 2x/4x and Gaussian-reference studies are supplied here as the final publication data products; their large intermediate state files are not included.

## 5. Controlled collision-level validation

`validation/engineered/dsmc_extended_validation.py` samples displaced Maxwellian incoming legs and checks the scalar stress law and heat–stress contraction directly at the collision level:

```bash
cd validation/engineered
python dsmc_extended_validation.py
```

It writes `extended_dsmc_validation_results.csv`.

## 6. Mapping data to figures

See `publication_data/figure_data_manifest.csv` for a panel-by-panel map from the Letter/Supplement figures to the corresponding CSV or JSON file.

The repository intentionally contains **data tables rather than manuscript figure PDFs**. This keeps the scientific data separate from journal typesetting and allows the same numerical values to be replotted in any style.

## 7. Quick integrity check

Install the numerical dependencies if needed:

```bash
python -m pip install -r requirements.txt
```

Then run

```bash
python check_repository.py
```

The check regenerates the exact coefficient tables, regenerates the wall-driven aggregate tables from the retained replica JSON files, regenerates the baseline shock tables from `shock_M5_crossrep.json`, and verifies that every entry in the figure-data manifest points to a bundled file.

## Notes on normalization

The coefficient CSV follows the manuscript convention used by `generate_hard_sphere_PQ.py`; the final column is labeled `value_over_kappa_sqrtpi`. The Hermite basis is the normalized probabilists' basis \(\mathrm{He}_\nu/\sqrt{\nu!}\). The simulation data files use the same hard-sphere normalization as the manuscript scripts from which they were generated.
